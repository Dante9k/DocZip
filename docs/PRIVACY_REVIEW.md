# 公开前隐私审查

审查日期：2026-10-22。范围为 DocZip 的受版本控制文件、完整可达 Git 历史、提交作者与提交者元数据、运行时数据流，以及 GitHub 发布附件和 Actions 制品。忽略目录中的本地缓存与实际输出不属于公开仓库的内容。

## 检查结论

- 未发现项目源码或历史中包含访问令牌、私钥、账户密码、个人主目录路径、真实输入文档、用户截图或任务结果。
- Git 作者与提交者使用 GitHub 隐私邮箱。公开仓库仍会展示 GitHub 账号、提交时间和正常提交历史。
- 测试文档由代码合成，不使用真实业务文档；唯一二进制源码资产为从 SVG 生成的应用图标。
- GitHub 仓库没有发布附件或 Actions 制品。安装程序、本地网页版压缩包、依赖、日志和测试结果均位于忽略目录，没有进入 Git 历史。
- 桌面界面阻止 HTTP、HTTPS 和 WebSocket 请求；网页版压缩代码没有外发网络调用、统计或遥测。测试脚本中的请求仅用于读取本地合成样本及浏览器 Blob。
- 桌面版会在本机用户配置目录保存输出文件夹和档位；网页版仅保存档位，任务和处理结果保留在当前页面内存。这些配置不随源码发布。

## 严格扫描结果复核

通用扫描器标记了七处疑似联系地址。逐项复核后均为误报或公开第三方信息：

- 工作区配置中的一处是依赖补丁文件名，版本号中的 `@` 被误识别为邮箱。
- 锁文件中的一处来自 `glob` 依赖的弃用提示；已与 npm 官方元数据逐字核对，是维护者公开的支持联系方式。
- 其余五处来自 `web/NODE-LICENSE.txt` 的上游版权与维护联系信息。该文件已与 Node.js 官方 `v24.19.0` 的许可证原文逐字节核对（统一换行后）；不是本项目用户信息，按许可证要求保留。

仓库检查器只对已核实的精确补丁文件名，以及官方许可证和弃用提示固定 SHA-256 对应的联系地址作明确豁免。令牌、私钥和个人路径等规则仍扫描完整内容。未发现需要撤销凭据或重写历史的问题。

## 持续检查与发布保护

`pnpm privacy:check` 扫描当前受版本控制文件及全部可达历史，输出风险类别和位置，不打印命中值。GitHub Actions 使用完整历史运行该检查，并验证代码格式、构建和测试。

真实文档、配置、凭据、截图和常见诊断转储受到忽略规则保护。网页版打包器只归档明确列出的交付文件，不再递归收集旧输出目录，因此遗留文档或日志不会被误打包。

自动模式检查不能证明所有自由文本均无敏感信息；新增文档、图片、配置和发布附件仍须人工审查。本记录不代替对以后提交的检查。
